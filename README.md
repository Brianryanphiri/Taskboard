# 📋 Taskboard

![Badge: License](https://img.shields.io/badge/License-MIT-green)
![Badge: GitHub Followers](https://img.shields.io/github/followers/YOUR_GITHUB_USERNAME?style=social)

**Taskboard** is a modern **project management application** designed to streamline workflows and improve team collaboration. It centers around a **Kanban board** for task visualization and an **Analytics Dashboard** that provides actionable insights such as **assignee workload distribution** and **project momentum tracking**.

By combining **intuitive task management** with **real-time insights**, Taskboard becomes a single source of truth for teams aiming to stay organized and productive.

---

## 🌟 Features

* 🗂 **Multi-project support** — create and manage multiple projects from one dashboard.
* 📌 **Kanban board** — drag-and-drop tasks across statuses: *To Do, In Progress, Review, Done*.
* 📊 **Analytics dashboard** — track progress and workload with interactive charts.
* 💾 **Local persistence** — tasks and projects are saved in the browser.
* 🌐 **Responsive design** — optimized for desktop and mobile.
* ⚡ **Modern UI** — built with **TailwindCSS** and **ShadCN UI components**.

---

## 💻 Tech Stack

**Frontend Only:**

* ⚛️ **React (Vite + TypeScript)** — fast, scalable frontend framework.
* 🎨 **TailwindCSS** — utility-first responsive styling.
* 🧩 **ShadCN UI + Radix UI** — prebuilt, accessible UI components.
* 🔄 **React Query (@tanstack/react-query)** — client-side data management & caching.
* 🖼 **Lucide Icons** — modern icon set.

> *All data is persisted locally in the browser using `localStorage`.*

## ⚙️ Installation & Setup

### Prerequisites

* [Git](https://git-scm.com/)
* [Node.js](https://nodejs.org/) (v18+)
* [npm](https://www.npmjs.com/) or [Yarn](https://yarnpkg.com/)

### Setup

```bash
# Clone the repo
git clone https://github.com/Brianryanphiri/Taskboard
cd taskboard

# Install dependencies
npm install
# or
yarn install

# Start development server
npm run dev
```

👉 App runs at: `http://localhost:5173/`
